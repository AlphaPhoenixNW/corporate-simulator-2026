# Executive Library | source and publication boundary

The companion book is integrated into the game as a complete 22-section reader with local bookmark, navigation, text-size controls and standalone HTML export. The owner accepts retention of the manuscript. The game and this repository were separately approved for public release on 26 November 2026; unrelated private source/history remains outside that approval.

The original imported manuscript remains unchanged. The in-game edition uses explicit section allowlists in src/library/sections-a.ts and sections-b.ts, with only the approved publisher-note and navigation wording edits. scripts/verify-companion-edition.mjs checks exact text and rejects unreviewed links or email addresses.

The source directory is not wholesale served. No private incident records, original repository history, internal editorial reports or credentials were imported. The 120 × 180 WebP original-cover thumbnail is used in the reader; full-resolution artwork has not been imported. The separate private editorial preview under playtest/ is built for validation but no longer uploaded in new Actions artifacts or included in dist. Superseded private artifacts were removed under EA-001; see publication review for evidence and scope. Preserve the original manuscript and artwork; do not add eager imports or expose private source material.

Source provenance is retained in [historical import notes](IMPORT_HISTORY.md). The current text review found no obvious personal safety concern; source history, cover provenance/metadata and licensing are recorded in the [publication review](../PUBLICATION_REVIEW.md).
