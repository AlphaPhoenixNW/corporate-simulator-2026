# Executive Library | source and publication boundary

The companion book is integrated into the game as a complete 22-section reader with local bookmark, navigation, text-size controls and standalone HTML export. The owner accepts retention of the manuscript. This does not authorise unrelated private source/history or change the repository's visibility.

The original imported manuscript remains unchanged. The in-game edition uses explicit section allowlists in src/library/sections-a.ts and sections-b.ts, with only the approved publisher-note and navigation wording edits. scripts/verify-companion-edition.mjs checks exact text and rejects unreviewed links or email addresses.

The source directory is not wholesale served. No private incident records, original repository history, internal editorial reports or credentials were imported. The 120 × 180 WebP original-cover thumbnail is used in the reader; full-resolution artwork has not been imported. The separate private editorial preview under playtest/ is an authenticated Actions artifact, not part of dist. Preserve the original manuscript and artwork; do not add eager imports or expose private source material.

Source provenance is retained in [historical import notes](IMPORT_HISTORY.md). The current text review found no obvious personal safety concern; source history, cover provenance/metadata and licensing remain separate [publication gates](../PUBLICATION_REVIEW.md).
